# Development Plan

Status: Living document
Last updated: 2026-10-17

How to use this:
- Check off `[x]` steps as they're finished, and add a line to the [Progress Log](#progress-log) at the bottom.
- **📄** shows the design docs to read before starting a step.
- **✅ Done when** lists each phase's exit criteria. Don't move on until they're met.
- **⚠ Decision** marks a step blocked on an open question in [open-questions.md](00-Overview/open-questions.md).
- **📝 Doc needed** marks a step that has no design doc yet. Write the doc first.

Guiding rule for a solo, part-time project: **make it fun offline with bots before networking anything.**

## Phase 2 — Combat & Per-Part Damage

📄 [health-and-damage](02-Mechanics/health-and-damage.md) · [weapons](02-Mechanics/weapons.md) · [aircraft-classes](02-Mechanics/aircraft-classes.md) · [flight-model](02-Mechanics/flight-model.md#part-damage-effects-on-flight)

- [x] Part detachment: remove hitbox, spawn falling debris, broken-edge cap

- [x] Body damage states: Healthy / Damaged / Critical with smoke, speed/climb penalties, gun jams

- [x] Target dummies / drone planes to shoot at

## Phase 5 — Bots

📄 [bots](02-Mechanics/bots.md) · [aircraft-classes](02-Mechanics/aircraft-classes.md) · [repair-and-landing](02-Mechanics/repair-and-landing.md) · [multiplayer](08-Technical/multiplayer.md)

- [x] Bot pilot using the same plane controller as players (input-driven): `BotPilot` with Cruise / FlyTo / Orbit / Pursue / FormUp orders (see [bots](02-Mechanics/bots.md))
- [x] Behaviors: patrol, chase, attack, evade missiles, avoid terrain: `BotBrain` (+ avoids other planes; see [bots](02-Mechanics/bots.md#behaviors-built-2026-10-16))
- [x] Bot retreats to repair when damaged: any lost part or body under 40% (or out of missiles/rockets with nobody around) → an approach lane home, glide-path final, repair, takeoff (see [bots](02-Mechanics/bots.md#retreat-to-repair-built-2026-10-16))
- [x] Difficulty settings: Easy / Normal / Hard presets (`BotSkill`) for detection, reaction, aim, missile evasion, ability use, retreat threshold and the stick hand; bots now use all four class abilities (see [bots](02-Mechanics/bots.md#difficulty-built-2026-10-16))
- [x] Bots fill empty team slots: `BotRoster` keeps both teams at 8 (player + 7 vs 8), class mix 3/2/2/1, patrols across the fight areas; plus combat tuning so an 8v8 actually scores kills (see [bots](02-Mechanics/bots.md#filling-team-slots-built-2026-10-16))

✅ **Done when:** a solo player can play a believable 8v8 against bots.
