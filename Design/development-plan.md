## Phase 6.5 — Mode Prototypes (offline)

📄 [match-modes](01-Game-Design/match-modes.md#shared-mode-framework-prototype) · [objectives](02-Mechanics/objectives.md) · [repair-and-landing](02-Mechanics/repair-and-landing.md) · [bots](02-Mechanics/bots.md) · [island-map](05-Levels/island-map.md)

Try three more modes against bots **before** networking, while changing the rules is still cheap. These are prototypes: get each one playable and fun enough to judge, not polished. Suggested order: framework → Capture the Banner (closest to Teams) → Airfield Domination (biggest; builds the capture system Phase 8 needs anyway) → Ram Royale (needs free-for-all, one life and ram damage).

**Framework**
- [x] Split mode rules out of `MatchManager` (win check, scoring, spawns, lives, loadout limits, HUD widgets, scoreboard columns); Teams becomes the first mode on it, behavior unchanged (existing match tests still pass): `MatchMode` + `TeamsMode` (see [match-modes](01-Game-Design/match-modes.md#framework-built-2026-10-19))
- [x] Game mode cards for each new mode (`GameModeInfo`), each with its bot difficulty: Banner, Domination and Ram Royale cards show IN DEVELOPMENT (dev builds only) until their rules exist (see [match-modes](01-Game-Design/match-modes.md#game-mode-cards-built-2026-10-19))
- [x] Per-mode arena on the Island: play area / boundary, spawn set, which airfields exist and what they do: `ModeArena` in the level, applied at the class pick; hard edges, closed airfields, air-start ring, arena patrols. Ram Royale's is built; the other modes use the Island as built (see [match-modes](01-Game-Design/match-modes.md#arenas-built-2026-10-19))
- [x] Scoreboard and end screen variants: each mode supplies its own columns and headline (`MatchMode.ResultLine`); Banner leads with captures, then team score. Fields held (Domination) and placement (Ram Royale) plug into the same two hooks when those modes get rules

## Phase 6.7 — Additional Maps *(planned, note added 2026-10-20)*

📄 [island-map](05-Levels/island-map.md) · [match-modes](01-Game-Design/match-modes.md) · [living-world](03-Art/living-world.md)

**Start this only after all the game types are in** (Teams, Domination, Ram Royale, Banner, plus any others from Phase 6.5). The Island has so far been the one map that every mode shares; once the modes are settled, build **different maps** shaped to how each mode actually plays.

- [x] Review each mode against the Island: what fits, what is cramped, what is missing (spacing, airfields, objective spots, sightlines, cover): [mode-map-review](05-Levels/mode-map-review.md), from the real layout plus bot-only survey matches (`MapSurveyTests`). Teams fits the Island; Domination works but sits in the south third and ends early; Ram Royale's arena is too tight and empty; Banner can't be judged until the bot runners actually grab
- [x] ⚠ Decision: the map list → **three maps** (decided 2026-10-26): **The Island** (Teams map; Banner stands closer and off the full AA, Domination fields spread north), **Broad Reach** (large, open plains and ridges), **Shattered Archipelago** (tight islands, stacks, canyon; Ram Royale arena with obstacles). Every map supports every mode (see [island-map](05-Levels/island-map.md#map-list-decided-2026-10-26))

**Heightmap terrain tool (replaces Blender for terrain)**
- [x] Editor tool `Winging It/Map/Build Terrain From Heightmap`: reads a grayscale heightmap (16-bit RAW `.bytes`, or a readable 8-bit image) plus a `MapDefinition` (world size, base and height range, sea level, seed) and writes the `TerrainData`, layers, trees and details; no Blender round trip: `Heightmap`, `MapDefinition`, `TerrainRules` (`Scripts/Maps`) and `MapTerrainBuilder` (editor)
- [x] Layer painting by rules on height and slope (sand near the sea, grass, rock on steep, snow high), so a new map needs no hand-painted splat; tree and detail scatter by the same rules and a seed
- [x] Bake the Island's `Height(x, z)` function to a heightmap, so the Island is the first map built by the tool and proves it matches today's terrain. Blender stays for models (planes, buildings, landmarks, props), not terrain
